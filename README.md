## 📝 Descripción del Proyecto
Este proyecto es un Producto Mínimo Viable (MVP) académico desarrollado para resolver la dispersión de documentación de los funcionarios del **Área de Salud de la Corporación Municipal de Quilpué (CMQ)**. 

La aplicación móvil proporciona un repositorio centralizado que permite gestionar, digitalizar y consultar antecedentes personales y laborales, garantizando la seguridad, el control de acceso según el perfil del usuario y la trazabilidad de la información institucional.

## 🚀 Funcionalidades Principales (MVP)
- **Control de Acceso (Roles):** Inicio de sesión con vistas y permisos diferenciados para Funcionarios, Personal Administrativo y Jefaturas.
- **Captura y Carga:** Digitalización de documentos físicos utilizando la cámara del dispositivo y carga de archivos digitales locales.
- **Visualización y Consulta:** Búsqueda y lectura de expedientes centralizados directamente en la pantalla, sin descargas locales que vulneren la seguridad.
- **Gestión de Flujo:** Verificación administrativa y aprobación/rechazo de solicitudes por parte de las jefaturas.
- **Trazabilidad:** Registro automático del historial de los documentos (quién subió, vio o modificó un archivo).

## 🛠️ Stack Tecnológico
- **IDE:** Android Studio (Jetpack Compose Template)
- **Lenguaje:** Kotlin
- **Interfaz de Usuario:** Jetpack Compose
- **Control de Versiones:** Git & GitHub
- *Nota de privacidad:* Este sistema opera estricta y exclusivamente con **datos ficticios/sintéticos** para garantizar la protección de datos en el contexto de salud.
